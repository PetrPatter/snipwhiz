# Snipwhiz

A screenshot tool for Windows 11: capture to the clipboard, keep every capture in
a library, annotate it later with objects that stay editable.

This glossary is grown lazily — a term arrives when it has actually been argued
about, not when it is first used. Its absence from this list means nobody has had
to be precise about it yet.

## Language

**Failed update**:
An update that did not install, leaving the app running the version it was already
running. The user is told nothing and loses nothing.
_Avoid_: Rollback

**Rollback**:
Returning to an older version after a newer one installed. **Snipwhiz has no such
capability.** A version that installs and then fails is not recovered from
automatically; the previous version's files remain in the packages directory, but
nothing in the app will go back to them.
_Avoid_: using this word for a failed update
